🇳🇬 Nigerian Sign Language App by: Mohammed Ishau

SignBridge

From Sign to Voice. From Voice to Understanding.

SignBridge is an AI-powered communication bridge for Nigerian Sign Language users — turning signed conversation into text and speech, and spoken replies back into text, in real time.

Key Features

  • Real-time NSL recognition — 24-sign MVP vocabulary
  • Two-way conversation — sign → voice, voice → text
  • Responsible AI — confidence threshold + UNKNOWN handling
  • On-device & private — camera footage isn't uploaded
  • Accessibility-first — contrast, text size, voice controls
  • Nigerian-validated — built with NSL signers & experts

Live, interactive build — tap through onboarding, start a conversation, and run the demo recognition flow right inside the frame.
